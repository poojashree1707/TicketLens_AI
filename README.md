### TravelDoc AI
### Overview

#### TravelDoc AI is an OCR-based travel ticket information extraction system built using Python, Streamlit, OpenCV, and Tesseract OCR.

#### The application allows users to upload travel tickets in image or PDF format and automatically extracts important travel information from the ticket.

#### It is designed to work with different types of transportation tickets such as bus, train, flight, ferry, and other travel tickets.

### Features

* Upload travel tickets in image or PDF format
* OCR-based text extraction with image preprocessing
* Automatic extraction of ticket and journey details
* Passenger, seat number, PNR, and ticket information detection
* Source, destination, operator, boarding point, and fare extraction
* Displays complete extracted OCR text through a Streamlit interface

### Technologies Used
  
* Python
* Streamlit
* Tesseract OCR
* Pytesseract
* OpenCV
* NumPy
* Pillow
* PDF2Image
* Regular Expressions

### Supported File Formats

### TravelDoc AI supports:

* JPG
* JPEG
* PNG
* BMP
* TIF
* TIFF
* WEBP
* PDF

### How to Use

* Start the TravelDoc AI application.
* Click the travel ticket upload option.
* Upload a ticket image or PDF.
* The application performs OCR processing.
* Travel information is extracted automatically.
* Passenger information is displayed when detected.
* Open View OCR Text to see the complete extracted text.
